# 院内急変対応トレーニング

初期研修医向け、院内急変対応トレーニングアプリ。8症例(敗血症性ショック／急性肺血栓塞栓症／低血糖による意識障害／消化管出血による出血性ショック／急性冠症候群／気道異物による窒息／アナフィラキシー／てんかん重積状態)を通じて、鑑別診断を当てることよりも「最初の5〜10分を安全に動く」ことに主眼を置いて学ぶ。

サーバー・APIキー不要、オフラインで動作する単一HTMLファイル。スマホ・タブレット・PCいずれでも利用可能。

## ローカルでの確認方法

`kyuhen-training.html` をブラウザで直接開くだけで動作する(ダブルクリック、またはブラウザにドラッグ&ドロップ)。

```bash
start kyuhen-training.html
```

## 医師が確認すべき医学的内容(要レビュー)

各症例の数値・薬剤選択は実在するガイドライン・論文をWebSearch/WebFetchで直接確認して記載しているが、以下は施設プロトコルや最新版ガイドラインとの整合性を医師の目でチェックしてほしい箇所:

1. **症例1(敗血症性ショック)**: RRS起動基準の具体的な数値(呼吸数9/30回・SpO2 92%・心拍数40/130・血圧90/200mmHg等)は施設や文献により異なりうる。自施設のRRS/緊急コール基準があればそちらを優先して確認してほしい
2. **症例2(急性肺血栓塞栓症)**: Wells scoreの具体的なカットオフ点数までは本文に明記していない(検査前確率評価の考え方のみ提示)
3. **症例3(低血糖)**: 50%ブドウ糖液20〜40mL(ブドウ糖10〜20g)という投与量は日本糖尿病学会の資料に基づくが、自施設の低血糖対応プロトコルがあればそちらを優先してほしい
4. **症例4(消化管出血)**: 輸血目標Hb値(非心血管疾患7〜9g/dL、心血管疾患合併9〜10g/dL)は複数のガイドライン間でトリガー値の記載に幅があるため、自施設の輸血基準と照合してほしい
5. **症例5(急性冠症候群)**: door-to-balloon 90分・12誘導心電図10分以内・アスピリン162〜325mgという数値は主に米国ACC/AHAガイドラインに基づく国際的に広く採用されている目安であり、JCSガイドラインでの完全に同一の記載までは一次資料で逐語確認できていない。周術期の抗血栓療法の可否判断は必ず執刀科と協働することを本文でも強調している
6. **症例6(気道異物)**: JRC蘇生ガイドライン2020の該当ページを直接確認できておらず、二次資料(検索結果の要約)に基づく記載。手技の順序・マギール鉗子の使用可否は院内の蘇生教育内容と照合してほしい
7. **症例7(アナフィラキシー)**: アドレナリン筋注の反復投与間隔(5〜15分毎)、二相性反応の観察時間(4〜6時間目安)は日本アレルギー学会ガイドライン2022のスライド資料に基づく
8. **症例8(てんかん重積状態)**: ジアゼパム/ミダゾラムの用量、第二段階薬剤(ホスフェニトイン・レベチラセタム)の位置づけは日本神経学会てんかん診療ガイドライン2018(追補2022)に基づくが、自施設採用薬・在庫状況により実際に使う薬剤は異なりうる

## 技術メモ

- 単一HTMLファイル(`kyuhen-training.html`)。外部依存はGoogle Fontsのみ(CSPで許可済み、それ以外は`'self'`/`'none'`、`connect-src 'none'`で通信を行わない)
- 進捗・自由記述の下書きは`localStorage`に保存(キー: `kyuhen_progress_v1`, `kyuhen_drafts_v1`)。プライベートブラウズ等でストレージが使えない場合は画面に警告を表示する
- 復習フラグ(自己評価「一部抜けた」「ほぼ言えなかった」)が付いた症例だけを絞り込める「復習」ボタンをホーム画面に表示
- 起動時に症例データの整合性(ID重複・必須フィールド欠落など)をチェックし、異常があれば`console.warn`に出力する
- 各症例の参考文献は実在・内容一致をWebSearch/WebFetchで検証した一次資料(学会ガイドライン、査読付き論文)を優先して掲載。二次資料(検索結果の要約)に依拠した箇所は上記「医師が確認すべき医学的内容」に明記した
- テーマカラーは既存の姉妹アプリ(発熱=teal、輸液=teal、抗菌薬=blue)と区別するため、ワインレッド系(`--primary:#8C1F3F`)を採用
